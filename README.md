# Paperkeep — 法律声明页

这是 Paperkeep 文档脱敏助手（Paperkeep Document Redactor）在 Microsoft Store
上架所需的公开声明页面，用 GitHub Pages 托管。

| 文件 | 用途 |
|---|---|
| `index.html` | 首页（指向两个语言版本） |
| `privacy.html` | 隐私政策（中文，商店「隐私政策 URL」填这个） |
| `privacy-en.html` | Privacy policy (English) |

页面为纯静态、自包含：不加载任何外部资源（无 CDN、无字体、无脚本、无统计），
不设置 Cookie。修改后直接覆盖上传即可。
