Paperkeep 文档脱敏助手 · 隐私政策

最后更新：2026-10-12

我们对隐私的态度可以概括为一句话：你的文件不离开你的电脑。

Paperkeep 文档脱敏助手（下称“本应用”）是一款完全在本地运行的 Windows 桌面应用。本政策说明本应用会接触哪些数据、这些数据存在哪里，以及我们不会做什么。

1. 我们不收集任何数据

本应用没有账号系统，不嵌入统计或广告 SDK，不会上传你的文件，也不收集任何使用数据。你添加的文档、检测结果、导出文件全部只保存在你自己的磁盘上，我们无法访问。

2. 保存在本机的数据

  • 应用设置（窗口位置、遮挡条样式、自定义关键词等）保存在本机用户配置中；
  • 运行日志保存在本机 %LOCALAPPDATA%\Paperkeep\paperkeep.log，仅用于排查问题；
  • 授权状态（是否已购买）保存在本机 %LOCALAPPDATA%\Paperkeep\license.dat，使用 Windows 系统自带加密（DPAPI）并与本机绑定，不包含任何个人身份信息；
  • 以上数据均不会上传或共享给任何第三方。

关于授权状态

应用在启动时（以及距上次确认超过 45 天时）会向 Windows 查询本应用在 Microsoft Store 的授权状态，用来判断是否已购买。这个查询由系统组件完成，不涉及你处理的任何文件，也不会向我们回传任何使用数据；两次确认之间的时间完全离线。你的文件全程只在本机读写。

3. 第三方组件

本应用使用的 OCR（文字识别）等组件全部在本机离线运行，不会把页面图像或识别出的文本发送到任何服务器。

4. 儿童隐私

本应用不收集任何人的任何信息，自然也不收集儿童信息。
